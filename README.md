# 🚀 Projet ProConnect

Bienvenue sur le projet **ProConnect**, un dépôt contenant deux applications distinctes développées dans un cadre pédagogique :

- 🧑‍🎓 **Client (B1)** → PHP natif  
- 🧑‍💼 **Dashboard (B2)** → Symfony  

---

## 📦 Installation du projet

Clonez le dépôt :

git clone https://github.com/Boursier-Enzo/projet-proconnect.git
cd projet-proconnect  

---

## 📁 Structure du projet

projet-proconnect/  
│  
├── client/        # Projet B1 (PHP natif)  
│  
└── dashboard/     # Projet B2 (Symfony)  

---

## 🧑‍🎓 B1 — Projet Client (PHP)

### 📍 Accès au dossier

cd client  

---

## 🧑‍💼 B2 — Projet Dashboard (Symfony)

### 📍 Accès au dossier

cd dashboard  

## 🎯 Objectif du projet

Ce projet permet de :

- Séparer deux niveaux de développement (B1 / B2)  
- Travailler sur deux stacks différentes (PHP & Symfony)  
- Simuler une architecture professionnelle multi-projets  
- Apprendre l’organisation d’un dépôt Git structuré  

---

## 👨‍💻 Organisation

- B1 → développement PHP simple
- B2 → application Symfony
